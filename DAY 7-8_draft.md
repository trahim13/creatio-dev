Как отладить именно этот процесс
1. Поставьте breakpoint в нужном месте

Откройте файл:

C:\ai-demo\creatio-instruction\runtime\dev1\Terrasoft.Configuration\Pkg\UsrYacht\Autogenerated\Src\UsrCalculateAvgTicketPriceProcess.UsrYacht.cs

И поставьте breakpoint внутри метода, который реально выполняется.

Обычно это что-то вроде:

Execute(...)

InternalExecute(...)

CompleteExecuting(...)

код ScriptTask / Formula / custom logic внутри процесса

Ставьте breakpoint на строку с исполняемым кодом, а не на сигнатуру метода, не на { и не на пустую строку.

2. Убедитесь, что Creatio пересобрал этот код

Так как это process-generated код, breakpoint сработает только если именно эта версия файла попала в загруженную сборку.

Сделайте:

в Creatio откройте Configuration

выполните Compile all

если вы меняли сам процесс — сначала сохраните/опубликуйте процесс, потом компиляция

Если есть сомнение, что контейнер держит старую DLL, перезапустите контейнер:

docker restart creatio83-dev1
3. Подключитесь к процессу в контейнере

В Visual Studio:

Debug

Attach to Process...

Дальше:

Connection type: Docker (Linux Container)
(у вас почти наверняка Linux container, потому что путь внутри контейнера /app/...)

Find...

выберите контейнер creatio83-dev1

После этого в списке процессов найдите:

dotnet

И attach к нему.

Если Visual Studio спросит код отладки, выбирайте:

Managed (.NET Core, .NET 5+)
или просто Automatic

Очень важный момент: вы дебажите не файл, а загруженную DLL

Физически breakpoint ставится в .cs, но реально отладчик цепляется к коду внутри:

Terrasoft.Configuration.dll

То есть схема такая:

файл .cs = исходник

выполняется = скомпилированная DLL в контейнере

breakpoint сработает только если:

загружена актуальная DLL

к DLL есть подходящий PDB

source сопоставился с тем файлом, который вы открыли

Если breakpoint “пустой” / неактивный / “The breakpoint will not currently be hit”

Это самый частый случай. Тогда проверьте по порядку.

Проверка 1. Загружен ли модуль

После attach:

Debug

Windows

Modules

Найдите:

Terrasoft.Configuration.dll

Если модуля нет — ваш код ещё не загружен или вообще не исполняется в этом процессе.

Проверка 2. Загружены ли symbols

В окне Modules напротив Terrasoft.Configuration.dll смотрите колонку Symbols.

Если symbols не загружены:

правой кнопкой по Terrasoft.Configuration.dll

Load Symbols

Если Visual Studio не может найти symbols — значит либо нет .pdb, либо он не совпадает с DLL.

Проверка 3. Совпадает ли source path

Контейнер видит путь так:

/app/Terrasoft.Configuration/Pkg/UsrYacht/Autogenerated/Src/UsrCalculateAvgTicketPriceProcess.UsrYacht.cs

А у вас файл открыт как:

C:\ai-demo\creatio-instruction\runtime\dev1\Terrasoft.Configuration\Pkg\UsrYacht\Autogenerated\Src\UsrCalculateAvgTicketPriceProcess.UsrYacht.cs

Это нормально, но иногда Visual Studio не может автоматически сопоставить путь.

Если Visual Studio при попадании в breakpoint или загрузке symbols попросит указать source file для пути вида:

/app/Terrasoft.Configuration/...

просто вручную укажите ваш локальный файл:

C:\ai-demo\creatio-instruction\runtime\dev1\Terrasoft.Configuration\Pkg\UsrYacht\Autogenerated\Src\UsrCalculateAvgTicketPriceProcess.UsrYacht.cs

namespace Terrasoft.Configuration
{
using System.ServiceModel;
using System.ServiceModel.Web;
using System.ServiceModel.Activation;
using Terrasoft.Core.DB;
using Terrasoft.Web.Common;
using System;
using System.Web.SessionState;

    [ServiceContract]
    [AspNetCompatibilityRequirements(RequirementsMode = AspNetCompatibilityRequirementsMode.Required)]
    public class YachtService : BaseService, IReadOnlySessionState
    {
        [OperationContract]
        [WebInvoke(Method = "POST", BodyStyle = WebMessageBodyStyle.Wrapped,
            RequestFormat = WebMessageFormat.Json, ResponseFormat = WebMessageFormat.Json)]
        public decimal GetMaxPriceByDriveTypeId(string driveTypeId)
        {
            if (string.IsNullOrEmpty(driveTypeId))
            {
                return -1;
            }

            Select select = new Select(UserConnection)
                .Column(Func.Max("UsrPrice"))
                .From("UsrYacht")
                .Where("UsrDriveTypeId").IsEqual(Column.Parameter(new Guid(driveTypeId)))
                .And("UsrStatusId").IsEqual(Column.Parameter(new Guid("49715cdd-ca8f-4c69-be62-f7f4d017e894"))) // 1. Operational
                as Select;

            decimal result = select.ExecuteScalar<decimal>();
            return result;
        }

        [OperationContract]
        [WebInvoke(Method = "GET", BodyStyle = WebMessageBodyStyle.Wrapped,
            RequestFormat = WebMessageFormat.Json, ResponseFormat = WebMessageFormat.Json)]
        public string GetExample()
        {
            return "OK!";
        }
    }
}
